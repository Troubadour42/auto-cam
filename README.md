# Auto Cam 1.0

Android app for the Samsung Z Fold. It records the front camera with `MediaRecorder.AudioSource.CAMCORDER`, the same microphone path Android gives the camera, not the phone-call microphone Chrome is stuck with.

Samsung’s own extra sound tuning inside the Samsung Camera app is not available to any other app.

## Install

1. Open the [v1.0.0 release](https://github.com/Troubadour42/auto-cam/releases/tag/v1.0.0) on your phone.
2. Download `AutoCam-1.0.apk`.
3. Allow Chrome to install unknown apps if Android asks.
4. Open Auto Cam and allow the camera and the microphone.

Version 1.0 records, plays the clip back, then saves it into Gallery → Movies → AutoCam, or deletes it.
